# 放假年龄 / FIRE Age

边算边学的财务自由、提前退休计算器。算出你几岁能开始放假，看懂每个参数，并知道做什么最能提前。

[English](README.en.md)

线上地址：上线后填写

## 它能做什么

- **正推**：按现在的节奏，几岁能放假。
- **倒推**：想在某个年龄放假，需要多存多少、多赚多少、少花多少，或今天需要多少本金。
- **跨国退休**：在一个地方攒钱，去另一个地方退休，按物价水平估算支出。
- **两种界面**：简单模式只问 7 个问题，专业模式开放全部假设，生成一次放假卡后打开。公式、数据来源和源码不需要解锁。
- **可核对**：公式、数据来源和授权条款全部公开，随机种子固定，结果可复现，可导出 CSV 和 JSON。

本工具不需要注册，不收集个人信息。你填的数字只保存在自己的浏览器里，分享卡片也在本地生成。

## 本地运行

需要 Node 24。网站本身没有运行时依赖，也没有构建步骤。

```bash
npm install             # 只安装测试工具
npm run serve           # http://localhost:4173
npm test                # 单元测试
npx playwright install chromium
npm run e2e             # 浏览器测试
```

## 目录

| 路径 | 内容 |
|---|---|
| `site/` | 网站，部署时发布这个目录 |
| `site/js/engine.js` | 金融模型（纯函数） |
| `site/data/` | 每一期市场数据的归档 |
| `functions/api/e.js` | 匿名访问统计接口 |
| `scripts/update-data.mjs` | 抓取并生成市场数据，每月自动运行 |
| `scripts/check-cn.mjs` | 测试大陆访问速度 |
| `data/assumptions.json` | 本工具的固定假设和来源清单 |
| `docs/` | 方法、数据来源、部署和内容指南 |

## 复现结果

在专业模式导出 JSON，里面有全部假设、随机种子、模拟次数和数据版本。公式见 [docs/method.md](docs/method.md)，来源见 [docs/data-sources.md](docs/data-sources.md)。发现算错了，欢迎提 issue。
