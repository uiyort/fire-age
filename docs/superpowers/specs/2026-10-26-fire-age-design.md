# 放假年龄 / FIRE Age — 第一阶段设计（传播获客）

日期：2026-10-26
现状：项目目录下的 `index.html` 是一个可用的单页 FIRE 计算器（正推/倒推、12 个国家和地区、多币种、蒙特卡洛、数据附来源）。本设计在它的基础上，做第一阶段的商业化：传播获客。

## 1. 意图与为什么

- 作者以个人身份推出一个中文财务自由计算器，第一阶段目标是传播，不收费、不留资。
- 成功的标志是"自来水"：不认识作者的人，自发在小红书、B站、豆瓣上推荐、晒这个工具。
- 产品定位是"边算边学"：小白能看懂每个参数，并主动学习、实践怎样优化；专业人士能核对算法和数据，并愿意认可。专业人士的认可本身就是一种自来水。
- 传播机制：用户在平台上看到内容，用手机打开工具算一遍，再回到原帖评论区晒自己的结果，引发即时留言，平台据此把内容推给更多人。

## 2. 目标、非目标、反目标

**目标**
- 大陆用户在手机上（包括小红书、微信、B站的内置浏览器）能稳定、快速地打开并完成计算。
- 结果能一键变成适合发评论的图片，并配一句文案。
- 每个参数都有易懂的解释、参考区间、对结果的影响，以及改善方法。
- 作者能用工具批量生成可直接发布的内容草稿。
- 算法、数据来源完全公开，可复现。

**非目标（第一阶段不做）**
- 账户、登录、云端保存
- 留资（微信、邮箱、表单）、收费、支付
- 微信小程序
- 自动发帖、自动评论
- 推荐具体基金、股票或理财产品

**反目标（即使功能都实现了，出现这些也算失败）**
- 小白第一次打开就被参数吓跑。
- 内容被平台判定为营销引流或违规理财，导致限流或封号。
- 专业人士发现算法或数据有错，并公开指出，而项目没有可核对的依据。
- 页面在大陆打不开或很慢。

## 3. 名称与文案（作者已确认）

- 中文名：**放假年龄**；英文名：**FIRE Age**。
- 副标题：财务自由 / 提前退休计算器（便于被搜索）。
- 金句：结果卡片和分享文案使用"从 41 岁起，余生皆假期"这种句式（数字按结果替换）。"余生皆假期"是伊坂幸太郎小说的中文书名，只能在句子里引用，不能当作产品名或品牌名。
- 正推结果的说法："你的放假年龄是 41 岁"。倒推结果的说法："想 45 岁放假，每月需存 8,600"。
- 语气乐观向上。结果不理想时也用积极的说法，例如"再坚持 11 年，你就能开始放假"。

## 4. 渠道（作者已确认）

- **小红书**：发 3:4 竖版图文笔记。笔记不能放外链，用户靠搜索"放假年龄"找到工具。
- **豆瓣**：在 FIRE、存钱、躺平、数字游民等小组发长帖，可以附链接。
- **B站**：作者不做视频，而是在相关热门视频下亲手写评论。评论草稿可以由工具生成，但必须由作者本人修改后手动发布。
- 内容统一打上 #FIRE #提前退休 等已有标签。

## 5. 范围（第一阶段）

### 5.1 公开网站

在现有计算引擎（`index.html` 里的模型部分）基础上改造。

**a. 手机优先的双模式**
- **小白模式（默认）**：只问 5–6 个问题，用大白话：年龄、已有存款或投资、每月收入、每月支出、想在哪里生活、想在哪里退休。其余参数按所在国家的数据自动填好。
- **专业模式**：展开全部参数，包括资产配置、各类资产收益、波动率、相关性、通胀、提取率、税费拖累、汇率漂移、养老金和领取年龄、规划年龄。
- 正推和倒推在两种模式下都可用。倒推保留现有的四种解法：多存、多赚、少花、本金。
- **退休地支出（设计者的默认方案）**：
  - "在哪里生活""在哪里退休"都是国家或地区，第一阶段不细分到城市。
  - 退休后每月支出，默认等于当前支出按两地的价格水平换算，不是简单按汇率换算。价格水平用世界银行的购买力平价（PPP）相关数据，许可为 CC BY 4.0，可以再发布。
  - 页面上明确标注"估算值，请按你计划的实际生活改写"，用户可以直接修改。
  - "换一个更便宜的退休地"这个杠杆，使用同一套价格水平数据。
  - 城市级生活成本需要商业数据，留到以后再做。
- **养老金（设计者的默认方案）**：
  - 小白模式增加第 7 个可选问题："预计每月养老金"，可以不填。
  - 结果同时显示两个年龄："算上养老金 41 岁 / 不算养老金 44 岁"。这样既不会因为不填而让结果过于悲观，也不会因为默认值而显得过于乐观，同时让用户直观看到养老金的作用。
  - 不提供按国家估算的默认养老金，因为金额取决于个人的缴费年限和基数。

**b. 参数学习卡**
- 每个参数配一张卡，内容包括：
  - 一句话说明它是什么；
  - 用户当前的数值和参考区间，参考区间附来源；
  - 它对这位用户结果的影响，例如"收益每提高 1%，放假年龄提前 2.6 年"，按用户自己的数据实时计算；
  - 普通人能怎么改善，只讲原则，不提具体产品。
- 小白模式里，卡片在点击参数时展开；专业模式里，卡片可以常驻显示。

**c. 你的最大杠杆**
- 自动对每个可调参数做同等幅度的合理变动，例如支出 −10%、储蓄率 +5 个百分点、费率 −0.5%、退休地换成生活成本更低的地方。
- 按"放假年龄提前了多少"排序，展示前三名。
- 这是"看懂"到"去做"的关键一步，也是晒图素材。

**d. 小目标与回访对比**
- 用户可以给自己设一个目标，例如"本月储蓄率达到 45%"。
- 再次打开时，展示和上次相比的变化。
- 数据只存在用户浏览器的本地存储里。存储不可用时，页面仍能正常工作，只是没有回访对比。

**e. 结果卡片**
- 一键生成 PNG 图片，在手机内置浏览器里能长按保存。
- 尺寸适合当评论配图：小而清晰，一眼能看懂。
- 内容包括：放假年龄、关键数字（例如成功率、所需资产）、金句、工具名"放假年龄 / FIRE Age"，以及搜索提示（例如"搜：放假年龄"）。
- 同时生成一句配套的评论文案，提供"复制"按钮。
- 卡片上不放二维码和链接（小红书对此敏感），只靠名字引导搜索。
- 设两个分享时机（作者已确认）：
  - **放假年龄卡**：算出结果时生成，内容如上。
  - **小目标达成卡**：用户回访时，如果 5.1 d 的目标已达成，就生成这张卡，例如"储蓄率到 45%，放假年龄提前了 2 年"。
- 两张卡都在浏览器本地生成，图片不上传。

**f. 给专业人士**
- 方法页：公开全部公式和假设，以及数据的来源和日期。
- 蒙特卡洛使用固定随机种子，结果可复现；页面上显示种子和模拟次数。
- 能导出全部假设和逐年数据（CSV 和 JSON）。
- 页面上显示数据版本号，例如"数据版本 2026-11"。
- 数据来源页列出每个来源的授权条款。

**g. 合规文案**
- 页脚和方法页写明：本工具仅用于教育和测算，不构成投资建议。
- 全站不出现具体产品推荐，也不出现收益承诺用语（如"稳赚""保本""暴富"）。

### 5.2 内容生成器（只有作者自己用）

- 一个独立页面，不出现在公开导航里。
- 输入几组人物参数，比如"上海 · 30 岁 · 月入 2 万"，或"深圳工作 → 吉隆坡退休"。
- 产出三类草稿（图片和文字的分工见本节末尾）：
  - **小红书图卡组**：每组 4–6 张，1080×1440，包括封面、结果、杠杆、学习点和结尾提问，另配标题和正文；
  - **豆瓣长帖**：真诚分享的口吻，带数据和计算过程；
  - **B站评论草稿**：针对常见视频话题，例如"多少钱能躺平""提前退休"，每条都带具体数字。
- 每条内容都以提问结尾，引导评论，例如"评论区晒出你的放假年龄"。
- 所有内容由作者下载或复制后手动发布。生成器不连接任何平台账号。
- **图片和文字的分工（作者已确认）**：
  - 生成器是纯网页，只负责图卡，并导出每个人物的计算结果（JSON）。
  - 笔记标题和正文、豆瓣长帖、B站评论草稿，由作者在 Claude Code 会话中根据导出的结果让 Claude 撰写，避免模板化的千篇一律。
  - 生成器不接入任何 AI 接口，仓库里没有密钥。

### 5.3 数据更新（全自动）

- 作者决定：不做需要手工的部分。所有市场数据由脚本从允许再发布的官方或公共来源自动抓取，每月由定时任务运行，通过测试后自动发布。
- 来源：欧洲央行（汇率、德国国债）、世界银行（价格水平）、BIS（CPI）、美国财政部、英格兰银行、日本财务省、澳大利亚储备银行、加拿大央行（各自的国债）。
- 中国和香港的 10 年期国债没有可再发布的自动来源（中国货币网的条款不允许未经授权转载，金管局接口字段为空），因此使用标明"假设"的固定值，不自动更新，用户可在专业模式修改。
- 每个数值都带来源网址、观测日期、抓取日期。单个字段抓取失败，或跳变超过 20% 时，沿用上一版并标注"沿用旧值"。
- **国家范围随之调整**：
  - 工作地和退休地都可选：中国大陆、美国、德国（欧元区）、英国、日本、中国香港、澳大利亚、加拿大。
  - 只能选作退休地（只需要汇率和价格水平）：新加坡、马来西亚、泰国。新加坡如果找到可用的自动来源，就升级为工作地。
  - 去掉：中国台湾（没有可自动获取的数据）。

### 5.4 托管与上线

- **部署到 Cloudflare Pages（作者已确认）**，连接 GitHub 仓库，推送后自动部署。不需要备案。
- **传播前自动测速**：脚本通过公共探测网络从大陆发请求。通过标准：超过半数探测点在 3 秒内返回成功。
- **作者决定不做手工部分，因此**：
  - 不做 ICP 备案，也不迁国内云。
  - 不人工测试小红书、微信、B站的内置浏览器。这是一项已知风险：探测点多在数据中心网络，结果偏乐观，而且测不出微信是否会拦截链接。
- **费用**：任何要花钱的事项（如域名），先把预估发给作者确认，确认前不做。
- **作者一次性要做的事**：注册 GitHub 和 Cloudflare 账号、付款（如果买域名）、提供部署令牌。之后的部署由脚本完成。
- 页面不依赖大陆无法访问的外部资源。现有页面用的 Google Fonts 在大陆加载不了，改用系统字体。

### 5.5 统计

- 接入一个大陆能访问、不收集个人信息的访问统计（可以自建，也可以用国内服务）。
- 需要记录的事件：访问、完成一次计算、切换模式、展开学习卡、生成结果卡片、复制文案、导出数据。
- 来源区分：用 URL 参数，或用每个渠道专用的路径或短码。因为小红书不能放链接，这部分会以作者在评论区和私信中发出的链接为主。

### 5.6 开源

- 代码放在 GitHub 公开仓库，许可证用 AGPL-3.0。
- 仓库包含：README（中英文）、方法文档、数据来源清单、数据更新脚本。
- 内容生成器也开源，但页面本身不公开挂链接。

## 6. 约束

- 个人主体，没有公司。
- 主要用户在中国大陆，使用手机，多在 App 内置浏览器里打开。
- 第一阶段不收集任何个人信息。
- 理财内容合规：只做测算和教育，不推荐产品，不承诺收益。
- 平台规则：不做自动化发帖或评论。
- 数据授权：只使用允许再发布的数据源。

## 7. 成功衡量（第一个月）

主要看自来水信号：
- 在小红书、B站、豆瓣搜索"放假年龄"，能搜到不是作者发的内容；
- 别人的帖子或评论里出现本工具生成的结果卡片；
- 不是来自作者内容的访问占比在上升。

辅助指标：完成计算数、结果卡片生成数、学习卡展开数、作者每条内容下的评论数。

## 增补（2026-11-07）：让结果更有传播力

作者看过 16Personalities 和 1in8b 的传播分析后，确认在第一阶段加入以下四项。全部基于现有模型和数据，不增加成本，也不增加手工操作。

1. **数字翻译成感受**：结果和杠杆都用"周一"表达，例如还有 574 个周一就放假。工作日按每年 250 天估算。
2. **放假类型**：由输入和模型结果按公开规则判定的 9 种类型，分 4 组。判定规则写在方法页，不做恭维式描述。
3. **同样的钱，在哪放假最早**：全部国家按放假年龄排序，支出按物价折算，养老金只按汇率换算。必须注明未计入签证、税务和医疗。
4. **抽一条人生**：从同一模拟里抽 4 条路径并讲述关键年份。主结果仍用固定种子，抽取的种子显示在页面上，可复现。

不做：恭维式人格描述、用户投稿或纪念空间、让主结果随机。
