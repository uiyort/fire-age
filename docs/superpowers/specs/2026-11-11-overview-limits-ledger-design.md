## 1. 为什么做

### 1.1 作者的原话（全部有约束力）

1. "请专家以市面优秀的报表填写案例的边栏设计为参考，增加条目总览和模块讲清楚数据故事和计算逻辑，关系密切的每月支出，房租房贷等应该有强数据限制而不是仅是文字提示"
2. "拦住了吗，哪里拦的，怎么拦的，为什么拦，都要说清楚，不能仅靠提示"
3. "框架为先，讲解在后，好的设计应该少讲解多框架"
4. "整个页面要轻量化设计，能用符号元素就用，少文字但不少表达"
5. "区分好简单和专业版，简单不能复杂得让人走不完整个流程，专业版不能少任何一处考虑"

## 2. 目标、非目标、反目标

**目标**
1. 每一处限制都回答四问：拦住了吗（结果上的胶囊和 `—`）、哪里拦的（胶囊上的项名、分组 `✕`、红实线框）、怎么拦的（结果停下，卡和导出不出）、为什么拦（格子下面一行不等式）。
2. 相关数字之间的关系由页面强制：派生并锁定、拦住加一键出口，不再悄悄丢项或悄悄改值。
3. 一份条目总览：手机上就是表单的分组标题加状态，宽屏是可折叠的边栏加结果卡。
4. 一本账本：把"你的数字怎么变成年龄"按计算顺序排成行，收起时就是原来的"放假资金"那一行。
5. 一个数只算一次：格子下面的行、分组标题、边栏、账本、顶栏都从 state.js 的同一来源取值。
6. 专业版看得到模型用到的每一项考虑（第 8.3 节）。

**非目标（这一批不做）**
- 手机下拉浮层总览、容量条、单独的核对页、逐年现金流表、第一次来时按钮上方的计数行。
- 改模型：收入增长默认 2% 不改，八成、2,000 次、种子不改。改的只有"悄悄丢掉/改值"变成拦住，以及两处显示口径（第 9 节）。
- 城市花销、孩子花销的参考值（约束禁止）。

**反目标（做了就算失败）**
- 简单版最短路径变长：用示例数，从第一次打开到拿到放假卡必须仍是 **填 0 格、点 3 下**；填自己的数仍是 4 格、3 下（第 8.2 节）。
- 第一屏多一个框。没有房贷或孩子的人，输入区最多多看到一行灰字（11-11 计划的约束）。
- 结构能说清的地方写一句解释。新增的说明句子为 0；本文只保留第 10.9 节列出的几句。
- 被拦住或待填时，页面任何地方出现旧结果或用被拒收的数算出的数。
- 打字中途闪红；禁用按钮。
- 用户可见文字里出现"杠杆""解锁""🔒""裸放"。

## 4. 规则

### 4.1 规则表

处理方式只有六种：**派生锁定**（由别的格子算出，不能直接改）、**拦住**（结果停下）、**待填**（必填或半填的组）、**结束**（事实，删除线，不计入，不算问题）、**提示**（橙 `!`，照算）、**局部拦住**（只停这一行，不停主结果）。悄悄改值（"夹"）全部取消。
"相等"一栏写明相等时算不算拦住。范围上下限本身都允许（如年龄 16、85 都可以）。所有上下限都是本工具设定，写进方法页（第 9 节）。金额一律先换成同一币种再比。

### 4.2 时机

| 时机 | 做什么 |
|---|---|
| 打字中（光标在格子里） | 不判对错，不标红，不加新的拦住。若结果算不通只是因为正在打的这一格，结果保持原样，不重算、不变 `—` |
| 离开格子、按回车 | 判所有相关规则。不成立的：红框、那一行、分组 `✕ N`、胶囊、结果变 `—` |
| 点"算出我的放假年龄"、放假卡、生成放假卡、导出、换一批年景、顶栏指向结果区的链接 | 判全部规则（含没碰过的格子）。有问题就跳过去（见 4.3）。**按钮从不禁用** |
| 改对了 | 输入时一旦规则成立，立刻去掉记号、重算结果，不等离开格子 |
| 打开页面时已存的数就有问题（含旧版本存下的"月供 ≥ 支出"） | 直接进入拦住状态，所有记号都显示，和今天打开时就标出空格一样（`app.js:1193`） |

依据：GOV.UK 的校验模式（不在打字中校验、提交时给汇总）和"不禁用按钮"（https://design-system.service.gov.uk/patterns/validation/ 、https://design-system.service.gov.uk/components/button/ ，X2 第一轮核对过）。这里没有提交按钮，所以"离开格子"就是提交。

### 4.3 被拦住或待填时停什么、跳到哪

- **结果**：顶栏和大字 `— 岁放假`（专业版 `财务独立 — 岁`，C39）加胶囊。凡是由结果算出的东西一律**隐藏**，不是变淡：大字下面的把握、攒够几个月、人生条、周一数、10 个小人、类型、`已算：…` 标签，以及结果区所有 zone、换个地方放假、放假实验室、专业版磁贴（C18）。只留 `— 岁放假` 和收起的 `放假资金 — ▸`。今天待填时变淡并保留旧数的做法一起改掉（`app.css:88` 的 `.inputs-missing` 改成隐藏）。
- **不能做**：生成放假卡、导出、换一批年景。点它们和点顶栏的 `怎么提前`、`撑得住吗`、`放假卡` 一样，走 `stopAtProblem()`。`参数`（学习区，不依赖结果）和 `我的数字` 照常。
- **跳到哪**：`stopAtBlank()`（`app.js:718`）改名 `stopAtProblem()`。先待填后拦住，同类按页面顺序取第一个；打开"改我的数字"（手机）或展开边栏那一行（宽屏），打开所在的折叠区（拆开来加、有房贷或孩子？），滚到居中，光标放进红实线框那一格。点胶囊同样如此。
- **胶囊写什么**：有待填时写待填（缺数时根本没法算）：一处 `待填：<项> ›`，几处 `待填 N 处 ›`；否则写拦住：一处 `拦住：<项> ›`，几处 `拦住 N 处 ›`。项名见第 10.1 节。
- **账本**：仍能展开，停在被拦的那一行，之后全是 `—`（第 7.4 节）。

## 5. 结构：两个来源，五处使用

两个纯函数都写在 `site/js/state.js`，紧挨 `missingFields`；页面任何地方都不再自己算这些数或判这些关系。

### 5.1 `problems(S, data, thisYear)`

- 返回按页面顺序排好的数组，每项：`{ id, kind, group, field, compare, chip, rel, fixes }`。
  - `kind`：`'blank' | 'block' | 'ended' | 'flag' | 'local'`。`missingFields` 成为 `kind: 'blank'` 的一种情况。
  - `field`：红实线框那一格（"刚提交的那一格"由 app.js 传入的最后提交字段决定；没有时用规则表里的默认）；`compare`：红虚线框的格子列表。
  - `rel`：画那一行用的 `{ left: [{label, value}], op, right: {label, value} }`；结束类为 `{ label, value, fact }`。
  - `fixes`：`[{ text, aria, set: {field: value} }]` 或 `[{ text, focus: field }]`，原文见规则表。
- 覆盖第 4.1 节全部规则；相等的处理按表。
- `eventsOf`、`itemsYearly` 只在没有 `block` 时被调用；兜底分支保留但正常走不到。

### 5.2 `storyRows(S, data, thisYear, plan = null)`

- 返回账本 ① ② 段和所有格子下面的行：`{ key, section: 'now' | 'after', label, value, op, unit, status: 'est' | 'ended' | 'block' | 'tool' | 'flag' | null, field, tag, views: 'both' | 'pro' }`。
- `plan` 是已解出的结果（放假年份 t、参数 p）。没有 plan（拦住、待填、到不了）时，依赖它的格子值为 `null`，画成 `—`。所以"被拦以后写 —"不需要单独的代码路径。
- ③ 段（每个年龄的成功次数、r、σ、种子、插值）来自已有的 odds 结果，在 views.js 里拼，不重算 ① ②。
- 用到 `problems()`：被拦的行 `status: 'block'`，`rel` 和格子下面那一行是同一个对象（C6）。
- 拆开来加的三项存进状态（新字段 `S.split = { rent, food, other }`，和其他输入一样存进浏览器，刷新后还在；旧存档没有这个字段等于没拆）。直接改总数会悄悄清空三项的做法（`app.js:276-282`、`:799`）去掉：锁定后总数不能直接改。
