## 3. 方法页（`site/method.html`、`docs/method.md`）

- 限制表：`金额 ≥ 0` 加"每月支出大于 0；退休后每月想花填 0 算没填"；`安全提取率` 挪到"只提示"一栏；加一行"扣掉月供和孩子后每月支出剩下的少于 25%（只提示）"。
- "模型不包含"加一条：放假后汇率变化、养老金币种暂未区分。

## 4. 已知例子（测试用，2026-11 数据，今年 2026）

- 示例：30 岁、到手 12,000、支出 6,000、存款 20 万 → r 2.87%、σ 10.9%，49 岁每月存下 11,482，50 岁放假，`× 35`。
- 家庭：35 岁、存款 50 万、到手 30,000、支出 18,000、月供 7,500 到 2045、1 个孩子 3 岁每月 2,000 → 50 岁放假；放假头一年 197,987/年（简单版 16,499/月）；放假线 4,149,879；`× 21`；54 岁起 169,825/年（14,152/月）；55 岁起 102,000/年（8,500/月）。
- 每月支出 8,000、月供 7,500 到 2030、退休后估算 → A11：`└ 扣掉月供只剩 500/月 !`、`每月支出 + 月供 → 15,500`。
